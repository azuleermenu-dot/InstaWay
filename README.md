# InstaWay

InstaWay is an Android-first Philippine commute/navigation app.

## Stack
- Expo SDK 57 + React Native 0.86 + TypeScript
- Expo Router
- Supabase/PostgreSQL
- Original UI and independently sourced transport data

## Development
```bash
npm install
npx expo start
```

The Supabase project is configured through `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
